# DVPE — ideas for later

DVPE is not the current priority. These are future ideas, not implemented features or a commitment to a schedule.

- [ ] **Listen to a patch on the PC.** Add an audio preview for supported patches, starting with a small set of DSP blocks and an audio file input. Explore reusing the same DSP code as the generated Daisy firmware and compare outputs; clearly identify any differences. A PC preview does not replace testing on the Daisy hardware.
- [ ] **Compile firmware from the interface.** Explore integrating an installed Daisy toolchain so the user can compile an exported patch and see the result and compiler errors in DVPE. Keep the existing source export usable independently; compilation does not establish flashing or hardware behavior.

The earlier project plan already recorded [Web Audio Preview](PLANNING/MASTER_PLAN.md) as outside the initial MVP. These notes make the idea visible for future consideration; they do not change the historical MVP scope.
