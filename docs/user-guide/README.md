# DVPE User Guide

The main repository page gives the product overview and quick start. Detailed
GUI operation is kept here:

- [Block Diagram and Inspector guide](BLOCK_DIAGRAM_AND_INSPECTOR_GUIDE.md) —
  canvas workflow, connections, parameters, CV controls, design modes,
  persistence, export, keyboard shortcuts, and troubleshooting.
- [Block catalog reference](../reference/DVPE_Diagram_Block_Reference.md) —
  generated catalog of the available runtime blocks and parameters.
- [Field Mapping subtractive tutorial](../../dvpe_CLD/examples/field_mapping_subtractive_tutorial.md)
  — an example patch and hardware-mapping workflow.
- [Glassmorphism design tutorial](../../dvpe_DESIGN/dvpe_glassmorphism_ai_guide.md)
  — the visual principles behind transparent blocks, wire glow, readable UI
  chrome, and the current Inspector → Design workflow.

DVPE exports source files; building and flashing firmware remains a separate,
hardware-specific step.
