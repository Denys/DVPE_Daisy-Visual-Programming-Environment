Guitar Delay
Algorithms

A signal-processing and embedded-design review of clean feedback delay, fractional delay interpolation, modulation effects, tape transport emulation, BBD models, reverse/granular playback, pitch-shifted feedback, diffusion networks, and freeze methods. The report separates physical mechanisms from marketing labels and maps each family to a buildable pedal architecture.

1. Executive summary

01

One buffer, several read semantics

Most guitar-delay modes can share a circular-memory service. The meaningful architectural split is not “digital versus analog,” but fixed read offset, moving read position, transport-speed reconstruction, and block/grain scheduling.

02

Interpolation is part of the loop tone

A moving fractional-delay filter is repeatedly traversed by feedback energy. Its magnitude error and coefficient modulation therefore become audible coloration, not merely a small readout error. Linear interpolation is inexpensive but has a severe high-frequency droop at half-sample offset.

03

Tape needs transport semantics

Modulating an ordinary delay length creates Doppler pitch from the derivative of delay. A physical tape path instead relates pitch to the ratio of medium speeds at the record and playback events. These are not equivalent under feedback.[R7]

04

BBD character is a system

Credible BBD behavior comes from clock-dependent bandwidth, input/output filtering, companding, sampled-transfer artifacts, and distortion—not from “dark repeats” alone.[R12][R13]

05

Reverse and shimmer are schedulers

Reverse delay requires captured history and overlap-add; shimmer requires a pitch shifter inside or around the loop. Both need explicit seam policy, latency accounting, and anti-aliasing. A plain variable delay is insufficient.

06

Recommended product core

At 48 kHz: float32 state, cubic Lagrange/Farrow for continuously moving heads, dual-head crossfade for discontinuous time changes, a configurable feedback processor, and mode-specific read/scheduling adapters. External SDRAM is warranted for long stereo/reverse/looper modes.

Established A delay line is a memory and indexing primitive. Model-dependent “Tape” and “BBD” depend on which device behavior is being modeled. Recommendation Preserve a clean core and layer coloration; otherwise every character mode inherits the same irreversible artifacts.

3. Core feedback-delay model

The baseline is a delay line in a feedback loop, optionally with a frequency-dependent loop processor. This model exposes the two control axes that matter: time between recirculations and gain/phase applied per recirculation.[R1]

Figure 2. Universal feedback delay. Order of read, feedback processing, and write must be specified; it is not a harmless coding detail in transport models.[R7]

u[n] = x[n] + g · (F * d)[n]     d[n] = u[n − D]     y[n] = a·x[n] + b·d[n]
Hwet(z) = z−D / (1 − g F(z) z−D)For a linear time-invariant loop, a practical sufficient stability condition is |g| · ||F||∞ < 1. Nonlinear saturation may bound amplitude but does not remove the need to test bias, limit cycles, and transient growth.

Decay mapping

For scalar per-loop gain g, an echo recirculates every D/fs seconds. A −60 dB amplitude decay after T60 gives:

|g| = 10−3D/(fsT60)     ↔     T60 = −3D / (fs log10|g|)

For a colored loop, apply the same mapping by frequency: set the loop magnitude |G(ejω)| from a target T60(ω). This is more predictable than mapping a “feedback” knob directly to a raw coefficient.

Recommendation Reserve an explicit margin below unity after the complete loop processor. A shelving filter, interpolator, diffuser, and saturator can together create local gain peaks even when the front-panel feedback coefficient is below 1.

4. Fractional delay: the quality-critical primitive

A sample-accurate static delay needs only integer indexing. Any smooth modulation, tempo interpolation, pitch head, room-size change, or tape-wobble path requires non-integer read positions. Fractional-delay design is therefore central rather than optional.[R2][R3]

D[n] = N[n] + μ[n],   N ∈ ℤ,   0 ≤ μ < 1
μ(z)linear · Lagrange/Farrow · sinc · allpassd[n] μ[n] and neighboring samples select the reconstruction policy

5. Time-varying delay and pitch: four different policies

For y(t)=x(t−d(t)), moving the delay changes the read rate. This creates pitch by construction; smoothing a knob only spreads the transition.

r[n] = n − d[n]     Δr[n] = 1 − Δd[n]     pitch ratio p ≈ 1 − Δd[n]

Figure 4. A robust pedal chooses the retiming policy according to the user gesture: tape-style pitch sweep, transparent tap-tempo update, or deliberate glitch.

6. Flanging, chorus, vibrato, and modulated echo

These effects share a smoothly modulated fractional delay. The audible category is set by nominal delay, modulation depth/rate, dry/wet combination, feedback, and inter-channel correlation—not by a different underlying memory algorithm.[R4][R5]

Figure 5. The same modulated-delay core covers flange, chorus, and vibrato; routing and parameter ranges define the perceptual result.

Comb geometry

For equal-gain dry and delayed signals, destructive notches occur where phase differs by π:

fk = (2k+1)/(2τ),   k=0,1,2…

Moving τ sweeps the notch lattice. Feedback converts the simple FIR comb to a sharper IIR comb.

Historical operating ranges

Dutilleux’s tutorial lists typical ranges around flanging 0–15 ms, chorus 10–25 ms, slapback 25–50 ms, and echo above 50 ms; these are engineering conventions, not hard psychoacoustic boundaries.[R1] A listener study found musically useful vibrato/flange/chorus regions depend jointly on modulation rate and depth, with common practice around low single-digit hertz.[R6]

Recommendation For a guitar delay, use at least two modulation components: a slow quasi-periodic component for wow/chorus and a smaller band-limited random component for non-repeating motion. Stereo voices should share macro movement but decorrelate the fine component; fully independent wide LFOs often produce unstable image wander.

7. Tape delay: transport first, coloration second

A tape-delay emulation has two separable layers: where/when the historical sample is read and what the record–medium–playback chain does to it. Combining both under one “wow/flutter” LFO obscures the mechanism.

7.1 Length modulation versus speed modulation

Figure 6. Length-type modulation ties pitch to delay derivative. Speed-type tape transport ties it to the speed ratio at entry and exit; the distinction matters strongly in feedback.[R7]

Fixed head spacing L:   ∫tᵢtₒ v(τ)dτ = L     pitch ratio = v(tₒ)/v(tᵢ)

Zavalishin and Parker show that directly varying delay length and emulating a moving medium have different feedback behavior. Their numerical transport method stores an integrated speed coordinate and searches for the read event; it is mostly O(1), O(log K) during speed-up transitions, and O(K) when full anti-alias filtering of speed-up is applied.[R7]

7.2 Grey-box tape chain

Figure 7. A physically informed tape chain. Chowdhury’s model combines record/play filters, magnetic hysteresis, variable delay/flutter, and speed-dependent loss.[R8]

Model-dependent Chowdhury used 16× oversampling in one Sony TC-260 model to represent a 55 kHz bias and nonlinear aliasing. That is evidence for that modeled chain, not a universal tape-pedal requirement.[R8] For an embedded delay, oversample only the nonlinear sub-block unless measurements justify a wider rate increase.

8. Bucket-brigade delay (BBD): clocked analog memory

A BBD is sampled-time but not digital: charge packets advance through capacitor stages under a two-phase clock. A complete effect includes clock generation, anti-alias/reconstruction filters, companding, and feedback routing.[R12]

Tdelay = N / (2 fCP)     approximate signal band edge ≤ fCP/2

Figure 8. BBD system topology and modeling options. The surrounding filters are functionally coupled to the changing clock rate.

Example: a 4096-stage BBD at 300 ms requires fCP≈6.83 kHz, leaving an approximate upper signal band around 3.41 kHz before practical margin. A 1024-stage device at 10 ms requires 51.2 kHz. These numbers explain why long BBD echoes become intrinsically bandwidth-limited rather than merely EQ-dark.[R12]

Fixed-rate model

Fractional addressing emulates clock-varying delay at the host sample rate. It is convenient but can generate interpolation and rate-conversion artifacts not present in the physical chip.

Variable-rate combined model

Holters and Parker use the surrounding filters as the rate-conversion interface, reducing the need for a separate interpolator and its distortion.[R13]

Latest directly relevant work found Gabrielli, D’Angelo, and Squartini (DAFx-25) apply polyBLEP correction to discontinuities in a digital BBD simulation, suppressing simulator-generated aliasing while retaining alias components intended as part of the chip model. In their test setup, reported SNR improvement was 36.2 dB at 50 kHz and 27.8 dB at 90 kHz clock; these are setup-specific results, not guaranteed product figures.[R14]
Recommendation Offer a “BBD-inspired” mode unless a specific device/circuit is measured. Implement clock-linked low-pass behavior, compander-like envelope dynamics, stage/clock-dependent nonlinearity, and controlled alias/noise. Avoid claiming a faithful chip model from a dark loop filter plus random modulation.

9. Reverse delay and granular overlap-add

Real-time reverse cannot play future audio. It captures a finite past segment, reads that segment backward, and overlaps successive segments so the wet stream remains continuous. Grain ordering and sample ordering are independent controls in granular synthesis.[R18][R19]

y[n] = Σg w[n−gH] · x[ag − (n−gH)]

Figure 9. Two reverse grains offset by a hop and complementary windows form a continuous stream. The wet path necessarily has look-back/start-up latency; the dry path does not.

Window policy

A periodic Hann window with 50% overlap supports constant-overlap-add amplitude. Square-root Hann pairs are useful for equal-power crossfades. At high feedback, window normalization must remain exact enough to avoid systematic decay or growth.

Feedback placement

After OLA: each composite reverse phrase re-enters memory. Per grain: stronger granular identity. Before reverse scheduler: new forward input mixes into a recirculating history. They are musically distinct and should be explicit.

Recommendation For a compact pedal, start with two grains, L=250–1000 ms, H=L/2, periodic Hann, and quantized grain restarts for rhythmic mode. Add onset-aware or low-correlation seam selection only after the deterministic scheduler is verified; otherwise debugging causality and feedback energy becomes difficult.

10. Pitch-shifted delay and shimmer feedback

A pitch delay changes pitch without proportionally changing repeat duration. That requires periodic read-head reset/crossfade, time-scale modification plus resampling, or a phase-vocoder family—not merely a continuously drifting read pointer.

p = 2s/12     read increment = p     delay-distance rate = 1−p

Figure 10. Shimmer topology. With +12 semitones in the loop, repeat k is shifted by k octaves unless a parallel unshifted path or band limiting prevents runaway ultrasonic energy.

For p=2, a 2048-sample available delay span at 48 kHz lasts only 42.7 ms before the head must reset. Increasing span lowers reset rate but increases temporal blur and/or internal latency. Upward feedback shift also repeatedly compresses bandwidth toward Nyquist, so anti-alias filtering must be inside the loop.

11. Multitap, ping-pong, and stereo feedback matrices

Multitap delay is a sparse finite impulse response readout unless taps feed back. Stereo character comes from tap times, panning, filtering, and a feedback matrix. The matrix eigenvalues—not individual knob values—set linear stability.

Figure 11. Stereo delay with a general 2×2 feedback matrix. A scaled orthogonal matrix redistributes energy without adding matrix gain.

Ping-pong: A = [[0,g],[g,0]], eigenvalues ±g     Rotation: A=g[[cosθ,−sinθ],[sinθ,cosθ]]
Recommendation Keep tap panning outside the feedback matrix when possible. This separates the audible stereo image from stability tuning. Check mono sum: anti-phase rotations and Haas-scale offsets can produce large cancellations.

12. Diffused delay and feedback delay networks

A delay becomes reverb-like when echo density grows and energy is redistributed across several incommensurate delay lines. An FDN consists of N delays, attenuation filters, and a feedback matrix; unitary/orthogonal mixing is a useful lossless baseline before decay filters are applied.[R20]

Figure 12. Four-line FDN used behind audible taps. The discrete echoes remain intelligible at low diffusion and become a dense ambient tail as matrix recirculations accumulate.

For an N=8 Hadamard matrix, a fast Walsh–Hadamard transform requires N log₂N = 24 scalar add/subtract operations plus scaling, versus 64 multiplications and 56 additions for a dense 8×8 matrix. This makes structured orthogonal matrices attractive on embedded targets.

Per-line decay target: |Gi(ejω)| = 10−3Dᵢ/(fsT₆₀(ω))
Design boundary FDN theory is reverb literature, but it is directly useful for “diffused delay” when the direct taps and late network are kept as separate layers. Fractional allpass elements can resize delay lines without amplitude filtering, though modulation of recursive allpasses still needs transient tests.[R21][R22]

13. Freeze, hold, and endless sound

“Freeze” is not one algorithm. The design choice is what remains invariant: an exact waveform loop, a cloud of short grains, a frozen spectrum, or a statistical resonant model.

Loop hold

Stop writing, keep reading a captured ring segment. Lowest cost and exact timbre, but periodicity and loop seam are exposed. Crossfade endpoints or search low-error seam pairs.

Granular freeze

Sample grains from a bounded history with randomized position, size, and phase. Masks loop periodicity but can become diffuse/noisy and may weaken pitch center.

Spectral freeze

Latch STFT magnitudes; propagate or randomize phase. Stable sustained spectrum, but transients and phase coherence determine whether the result sounds metallic, static, or smeared.

Predictive / excitation freeze

Estimate a high-order linear-prediction filter from stationary audio and excite it with white or sparse velvet noise. Välimäki et al. report over 90% operation reduction using velvet noise versus standard convolution in their endless-sound method.[R23]

Figure 13. Freeze families differ by what representation is held and how motion is reintroduced.

Listening corpus

Use at least: muted single-note transients, clean arpeggios, dense distorted chords, palm-muted low strings, sustained harmonics, silence/noise floor, and knob/tap gestures during active feedback. Level-match algorithms within 0.2 dB where tone is compared; otherwise saturation and brightness preference are confounded by loudness.

Release gate No mode should be accepted solely because its nominal preset sounds good. It must pass wrap, transition, near-unity-feedback, and long-soak tests at the same parameter extremes exposed by MIDI/expression/control automation.

17. Conclusion and implementation recommendation

Recommended sequence

  1. Build the invariant core: circular memory, deterministic read-before-write semantics, integer/fractional head API, and feedback processor with measured loop gain.
  2. Ship the clean and modulated families first: DIGITAL, MOD, multitap/stereo. They validate memory, interpolation, control smoothing, tempo transitions, and loop safety.
  3. Add TAPE as a transport-aware layer: use speed semantics for time gestures; keep physical coloration modular. Do not couple every wow/flutter control to a single sine LFO.
  4. Add REVERSE and PITCH through a scheduler: shared windowing and crossfade infrastructure, but different read direction and rate.
  5. Add BBD only after deciding the claim: “BBD-inspired” can be perceptually designed; a named-device emulation requires a measured system model.
  6. Add DIFFUSE/FREEZE last: they reuse the stable delay core but add state density, complex feedback, and difficult subjective tuning.
Bottom line The strongest pedal architecture is a small set of rigorously verified primitives with mode-specific semantics. The weakest is a collection of unrelated per-mode buffers and hand-tuned hacks: it duplicates wrap/transition bugs, hides loop gain, and makes later stereo, MIDI, and preset morphing disproportionately difficult.
